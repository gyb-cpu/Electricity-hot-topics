页首说明：

## 1. 本站提供什么，不提供什么

本站抓取国家发展改革委、国家能源局、中国政府网、各地能源监管机构等渠道公开发布的政策文件、市场规则、项目进展和运行数据，生成中文标题、摘要和推荐理由，并把不同来源对同一件事的报道合并为一个事件。

本站不是政策发布机关，也不做政策解读。

- 本站不发布具有行政效力的文件，请以发布机关官网的正式文本为准。
- 摘要由模型生成，可能有遗漏、偏差或错误。涉及电价、容量补偿、辅助服务补偿、交易规则、监管处罚等具体条款的，请点开原文核对。
- 本站不预测电价，不提供投资建议。
- 政策文件的解读、评论与预测属于他人观点，不代表本站立场。

## 2. 原文版权与转载

- 标题、摘要和推荐理由由模型根据公开来源生成，算作本站的编辑成果。
- 原文版权归各来源所有。本站默认只展示摘要和原文链接，来源明确允许时才展示全文。
- 政府机关发布的政策文件，著作权归属按《著作权法》第五条等规定判断。本站不对此下结论，来源方提出要求的，按要求处理。
- 转载本站的摘要或日报内容，请注明出处，并先取得来源方对原文的授权。商业使用、批量抓取后再分发、放入付费产品，需要事先取得本站书面许可。

## 3. 来源方的更正与下架

如果你是政策发布机关、持证机构、媒体或原文作者，认为本站的摘要有错误、引用不当，或希望更正、下架、调整展示方式，请通过[反馈页](/feedback)联系我们，附上原文链接和具体要求。核实后我们会处理。

## 4. 接口与调用频率

RSS、公开 API 和 MCP 是匿名只读接口，不需要 API Key。

- 最小轮询间隔以响应头 `Cache-Control` 中的 `s-maxage` 为准。请带上 `If-None-Match`，未变更的资源会返回 304 和空响应体。
- 收到 429 或 503 时，请遵守 `Retry-After`，不要并发重试。
- 没有推送通道（无 SSE、Webhook 或流式接口），请按间隔轮询。
- 请求时带上 `Accept-Encoding: gzip` 或 `br`。
