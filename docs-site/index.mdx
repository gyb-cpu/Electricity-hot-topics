# 电力热点宝

从国家发展改革委、国家能源局、中国政府网、各能源监管机构和省级发改部门的公开发布栏目收资料，用模型预筛、独立打两次分，挑出真正值得看的，写成中文标题、摘要和推荐理由；把不同来源对同一件事的报道并成一个事件；每天早上 08:00 出一份日报，周报和月报从日报里汇编。

<Info>
  **聚合与摘要工具，不是政策发布机关。** 站内不转载政策原文，只给摘要和原文链接；一切以发布机关官网的正式文本为准。
</Info>

## 六步流水线

<Steps>
  <Step title="采集">
    RSS、网页列表、JSON 接口、X 账号、微信公众号，以及脚本推送。同址同文只留一份。
  </Step>
  <Step title="预筛">
    判断是不是本行业的事。`BLOCK` 的不出现在任何公开页面。
  </Step>
  <Step title="两次评分">
    同一份评分标准独立打两次（0–100），两次之和 ≥ 2 × 门槛就够分。
  </Step>
  <Step title="写作">
    等结构化完成再写：中文标题、答案先行的摘要、推荐理由。
  </Step>
  <Step title="归组">
    不同来源报道的同一件事聚成一个事件，事件页有综述。
  </Step>
  <Step title="成刊">
    日报按规则编排，周报和月报从日报里汇编。
  </Step>
</Steps>

每一步的提示词都在 `industry/prompts/`，**改标准不用改代码**。

## 你会得到什么

| | |
|---|---|
| **六种信源** | 分三级（官方一手、官方账号与准官方、媒体与个人），各级入选门槛不同；抓取频率按产出自动调整 |
| **精选** | 预筛，两次独立评分，再按信源分级的门槛决定入选；同一条新闻只占一条 |
| **写作** | 中文标题、答案先行的摘要、推荐理由，外文全文翻译 |
| **聚簇** | 同一事件聚成一条，后续进展挂在同一个事件下，人工改过的归属不会被覆盖 |
| **热点** | 按事件算热度：独立来源越多越靠前 |
| **日报周报月报** | 日报每天 08:00，周报每周一，月报每月 1 日 |
| **主题与搜索** | 机构与企业、业务方向、内容形态三类主题页 |
| **给 Agent 用** | 同一份内容给人看也给 Agent 用 |
