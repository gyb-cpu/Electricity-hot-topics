三、主体 subjects：资料实际讨论的机构或企业（不是顺带提及），用这些 id：{{entities}}。没有就给空数组。

四、资料范围 scope：只根据这篇资料自身判断，不能从候选报道反推。
- single：核心报道只有一个具体发生，或围绕该发生的一项测算、分析、回应。同一轮或同一份名单里发布的若干政策、项目或措施，以及这次发布里的执行安排、时间表与配套细则，属于 single。没有具体发生的单一观点或分析可以是 single，但 fact 为 null；不能用“讨论同一个议题”把多个发生合成 single。
- composite：正文实质性报道多个可以各自成条的发生、不同主体的措施或不同人的发言。先数清主体各自做了什么，再判 scope：同一天、同一份通知、同一个会议、同一批名单都不能把它们变成一次发生。会议回顾与多项目总览同理。仅把其他项目或主体用作背景、比较或例证，正文仍集中于一个发生或一项测算，则不是 composite。
- unknown：材料不足以辨认范围。不要仅凭标题词、篇幅或是否能抽到 fact 判断。

五、事实 fact：抽取本条资料当前报道的那次发生，供同事实归组使用：title（≤30 字），subject（做出动作的主体），action（本次动作），object（动作的具体对象），occurredAt（原文明示的本次动作发生日期 YYYY-MM-DD，未知为 null）。主管部门与机构发布的政策、规则以其自身为 subject，即使消息由下属账号或媒体转述；个人观点本身以发言者为主体，不因其任职单位就声称单位发布。composite 必须为 null；没有可确认发生的观点稿也可为 null。
先分清当前动作与背景：
- 主帖新增了测算、点评、回应或备案消息时，fact 必须是主帖的这次动作；引用的旧发文只说明被点评/回应的对象，不能代替主帖事实。例：券商主帖测算某地电价影响并引用某局原发文，主体是该券商，动作是发布测算，对象是电价变化，不是该局再次发文。
- 主帖仅转述或引介引用内容、自己没有另一项动作时，可以抽取引用中被转述的同一次发生；不要把一次转发本身虚构成新的政策发布。
- 新写的解读、复盘、盘点涉及既有发文时，抽取这次解读/复盘及其明确新增内容，不能因正文回顾了发文而仍写“印发/出台”。例：“上月印发了办法，今天解读执行影响”是解读；上月只属于背景发文，不能填作本次解读的 occurredAt。若正文明确表示该办法此时才正式生效，则按这次生效抽取。
- 发布时间、抓取时间、被引用内容的时间不能补作当前动作的日期。“今天”可结合本条原文发布时间解析；只有背景日期或没有明确日期时保持 null。
- 长期维护的机组档案、电价表、项目库和交易信息披露页，仅列出既有项目的日期、电价或电量，不等于本次开工、投产或调价。没有原文明示的新动作时，scope 为 unknown、fact 为 null；不能把“页面收录了”改写成“机构新发布了”。
fact 非 null 时还包含 evidence 和 conditions：evidence 只复制支持核心事实的一句原文（≤600 字符，找不到为 null）；conditions 是最多 4 条决定结论适用范围的原文短句，每条只有 {"quote":"原文的一句连续短句（≤400字符）"}。本步骤不翻译、不概括条件，只摘录。
evidence 必须支持上面选定的当前动作。主帖有新动作时从主帖摘取，不拿引用中的旧发布句子证明本次测算；只有主帖纯转述引用时才用引用内容的核心证据。
通读全文（包括文末的生效时间、适用范围和附注说明）后，条件优先级为：1. 适用范围（哪些省份、哪类机组、哪类用户）、执行时间与过渡安排，以及豁免情形，二者必须同时保留并指明各自对象；2. 价格、容量、电量等关键参数与结算口径；3. 试点、试行、未来才生效的限制。不要用规模数字或一般意义说明占用条件名额。没有明确条件才给 []，不把征求意见稿写成已印发。
每个 quote 只承载一句原文；不同位置的条件分别成项，不能串成一个段落。例：原文有 “自2026年7月1日起执行。” 和 “试点地区暂不执行本条。”，应输出 [{"quote":"自2026年7月1日起执行。"},{"quote":"试点地区暂不执行本条。"}]，不能写成 “自2026年7月1日起执行……试点地区暂不执行本条。”。保持原文语言和字符；超过长度就选较短的完整句子。不要翻译、改写、省略中间文字或自行加入 ... / …；拼接的引文会被丢弃。quote 必须是收到的原文正文/帖子里能连续查到的文字，不来自标题、来源标签或中文译文。

输出前核对当前动作（优先于标题和宣传措辞）：标题里的“印发”“出台”“重磅”不能覆盖正文明确的先后关系。正文若说此前已经发文、现在解读执行影响或梳理要点，本次 action 和 fact.title 必须写解读/梳理；只有正文明确该文件此时才首次印发，才写印发/出台。evidence 摘取当前解读/梳理的句子，不能摘背景发文句来证明新发文。没有明示本次解读发生在哪一天，occurredAt 必须为 null，不从文章发布时间或此前发文日期补齐。

只输出一个 JSON 对象，字段：category, tags, subjects, scope, fact。
