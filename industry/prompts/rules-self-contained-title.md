
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：发文机构名 / 项目名 / 企业名 / 电价与市场机制名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是文号、代号 / 没信息量的 teaser（如 "国能发电力〔2026〕45号"、"1号机组"、"今日"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题 "国能发电力〔2026〕45号" + 来源 "国家能源局" → "国家能源局印发国能发电力〔2026〕45号"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体项目、机组或文件名时，用上位词（如"某省电力现货市场"、"一项煤电项目"）兜底，绝不凭"行业常识"编一个具体的项目名、机组编号、电价或文号。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Comment / Outlook 这类解释、分析、解读、评论或展望型标题，中文标题必须保留这个类型；不能因为正文谈到一项已经发布的政策、一个已经开工的项目或一组新数据，就改写成"印发 / 出台 / 开工 / 投产 / 调价"。只有原标题明确宣布了印发、出台、开工、投产或调价，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、项目、公司名。
   例：原标题 "How capacity pricing changes coal plant economics" → "容量电价如何改变煤电的收益测算"，不能写成 "国家能源局发布容量电价新规"。
   例：原标题 "解读：绿电交易结算规则调整" + 来源和正文明确是某电力交易中心 → "某电力交易中心解读绿电交易结算规则调整"，不能只写成缺主体的 "解读绿电交易结算规则调整"。
